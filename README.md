# SNSアプリ（学習用）

旧Twitter風のSNSを、学習用に作るリポジトリです。140文字の投稿を書いて、みんなの投稿をタイムラインで読めるアプリを目指します。

技術構成は [収支管理アプリ（finance-manager-app）](https://github.com/NakamuraKazki051/finance-manager-app) と同じ Next.js + Ruby on Rails + MySQL です。
